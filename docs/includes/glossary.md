*[ADC]: Application Default Credentials: credenciales que las client libraries de Google y Terraform encuentran automáticamente
*[OAuth]: Open Authorization: estándar para delegar acceso a una app mediante tokens, sin compartir la contraseña
*[OIDC]: OpenID Connect: capa de identidad sobre OAuth 2.0 que dice quién es el usuario
*[IAM]: Identity and Access Management: quién puede hacer qué sobre cuáles recursos
*[CLI]: Command-Line Interface: herramienta que se usa desde la terminal
*[SDK]: Software Development Kit: librerías y herramientas para integrar un servicio desde código
*[API]: Application Programming Interface: contrato para que un programa llame a otro
*[WIF]: Workload Identity Federation: permite que workloads fuera de Google Cloud se autentiquen sin llaves de service account
*[SA]: Service Account: identidad para aplicaciones y workloads, no para personas
