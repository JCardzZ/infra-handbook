# Plan de estudio

El plan para pasar de backend engineering a cloud y platform engineering: qué estudiar, en qué orden y con qué proyectos demostrarlo. Empieza en GCP y sigue con AWS, Azure y multicloud.

- [Fase 0 — Fundamentos](fase-0.md): 16 semanas de fundamentos aplicados sobre GCP (Linux, redes, contenedores, Git y CI/CD sin llaves) que terminan en el *walking skeleton* de Puente.
- [Proyectos](proyectos.md): los cuatro proyectos del portafolio (Puente en GCP, Vitrina en AWS, Ruta en Azure y Faro multicloud), con su negocio, arquitectura, costo y certificación.
